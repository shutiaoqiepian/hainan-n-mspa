> 与气象学正名对齐，并给出可判断的天气条件与拍摄要点。

**规模**：102 条 ｜ 6 大类（霞 19、光束 13、冰晶光学 12、云 27、大气 16、平台口语 15） ｜ 有可验证来源 67 条，标「未找到」35 条

**机器可读版**：[`jargon.json`](jargon.json)（数组，每项 `{name, alias, scene, shoot, platform, source}`）

## 怎么读这份表

- **scene** 用天气语言写（云量分层、太阳高度角、AOD、风速、湿度），目的是能直接翻译成预报判断，而不是散文。
- **shoot** 只写一句话：焦段 / 曝光 / 机位，三者至少给一个可执行动作。
- **来源标记**：`★` = 本次抓取并打开原文核对过；`☆` = 只在检索结果里看到标题（内容未展开）；
  `未找到` = 没找到可验证页面，**没有编造链接**。
- 平台写「小红书 / 抖音」不等于该词只在小红书抖音存在，而是指**该叫法主要在这一侧流传**；
  「气象爱好者 / B站」多指专业圈，口语传播弱。

## 哪些词最适合放进预报提示

先给结论：**能进提示的词，必须是「用户出门 30 分钟内能抬头验证」且「我们能从现有数据算出来」的交集。**
两边缺一个都不行——算不出来的词会变成假精确，验证不了的词会变成废话。

### 第一梯队：建议直接进提示（成本最低、圈内认同度最高）

| 词 | 可用的判断字段 | 建议文案 | 为什么值得放 |
|---|---|---|---|
| 大烧 / 中烧 / 小烧 / 微烧 | `score` 分级（现成 LEVELS） | 「今晚中烧到大烧之间，西边一条会很艳」 | 追霞圈通用度最高的分级词，和分数天然一一对应 |
| 水晶天 / 湛蓝 / 通透 | `aod` 分档 | 「今天水晶天，颜色会很干净」 | 用户能直接感知「天蓝不蓝」，且 AOD 预报稳定 |
| 污烧 | `aod > 0.8` | 「今天污烧，颜色发灰，别专程跑」 | **反向提示比正向提示更攒口碑**：帮用户省一次白跑 |
| 回光返照 | `sunEl` −8°~0° 且 `high ≥ 30%` | 「日落后再等 10 分钟，常有回光返照」 | 直接提升成片率，且是纯时间提示，零误报成本 |
| 云被烧穿 | `high` 20–70% + `low ≤ 30%` + `sunEl` −6°~0° | 「云有缝，有机会被烧穿」 | 画面感极强，且条件可算，误报率低 |
| 鱼鳞云 / 排骨云 | `mid` 云量 + 云属 `Ac` / `Sc` | 「天上鱼鳞云，明天可能变天」 | 民间谚语自带传播力，还能顺带解释「为什么明天不建议跑」 |

### 第二梯队：有条件进提示（要加限定词，或只在特定页面出现）

- **丁达尔光 / 耶稣光**：用 `crep` 分。文案写「有耶稣光的机会」，不要写「会有耶稣光」——光条是否落地取决于云缝位置，模式分辨率不够。
- **云海 / 平流雾**：只在清晨场次、且 `low ≥ 45%` + `RH ≥ 88%` 时提；海南要绑定具体山头（五指山、尖峰岭），否则用户不知道去哪。
- **天空之镜**：这是**地景词不是天象词**，必须和「退潮时间 + 风速」一起出现才有意义；适合放在机位详情页而不是首页分数旁。
- **金星带 / 地影**：日落后转身就能看，几乎零成本；但它是「每天都有的常态现象」，只适合做科普卡片，不适合做「今天值得跑」的理由。
- **彩虹**：`rainbow` 分已有；提示里写「雨后有机会出虹」，并提醒「虹在太阳正对面」，比只报一个百分比有用。

### 不建议进提示（算不出 / 概率太低 / 会反噬可信度）

- **22° 晕、46° 晕、幻日、环天顶弧、环地平弧**：需要云相态（冰晶/水滴）与云底温度，免费数据只有分层云量百分比。硬报会把「卷层云」误当「有晕」。
- **绿闪、红闪**：概率极低且依赖地平线洁净度，报了等于骗人；最多做「冷知识」条目。
- **钻石尘、夜光云、极光**：海南几乎不可能出现，进提示只会显得不专业。
- **山帽云、马蹄云、滚轴云、迭浪云**：属于「偶遇型」，现有数据判不出；放在「今天可能看到什么」的科普列表里即可。
- **宝光**：需要人在云雾上方（飞机、山顶），是机位属性不是天气属性。

> 注：`phenomena.ts` 里现有的 `halo` / `sundog` / `lenticular` 等规则不必删除，建议保留但只作为详情页科普文案，不进首页「值得跑」的提示。

### 三条文案纪律

1. **一个提示最多两个黑话词**，其余用白话。黑话的作用是「让圈内人觉得你懂」，不是「让所有人看不懂」。
2. **报机会，不报现象**。用「有机会 / 大概率 / 值得跑一趟」，不用「会有 / 一定烧」。荆楚网报道里追霞博主普遍注明「仅供参考、不作为最终依据」，这是圈内共识。
3. **自己声明阈值**。「大烧 / 中烧 / 小烧」最初来自 SunsetBot、莉景天气、Windy 等 App 的分级，各家阈值不同；站内必须写清「我们的大烧 = 82 分以上」，否则用户拿别家 App 的「大烧」来对，会觉得你不准。

### 一个可落地的结构（与 `src/lib/forecast/phenomena.ts` 对齐）

词库 → 匹配规则时，建议每条给三个字段：`when`（人话条件）、`match()`（0/1/2 三档）、`confidence`（`高 / 中 / 低`）。
只有 `confidence = 高` 的词才允许出现在首页分数旁；`中` 放详情页；`低` 只做科普，不进任何「值得跑」的判断。
这样词库扩张不会稀释预报的可信度——**词多是加分，词不准是减分**。

### 口径与争议（写进词库时请保留）

- **丁达尔光 ≠ 严格意义的丁达尔效应**：丁达尔效应是胶体对光的散射，摄影圈把它借用来指「云隙光」（耶稣光、上帝之梯）。重庆日报的科普文把三者当同义词处理，本表沿用圈内口径，但 JSON 里保留了三个独立词条，方便产品按需合并。
- **鱼鳞云 ≠ 排骨云**：中国天气网明确「鱼鳞云」是透光高积云、「排骨云」是波状层积云。很多帖子混用，两者预示的天气也不同（前者多降雨，后者多冷空气大风），提示文案不能互换。
- **大烧 / 中烧 / 小烧 不是气象标准**：是预报 App 的鲜艳度分级，经追霞博主二次传播成为圈内通用语。
- **天空之镜是地景词**：指湿沙滩/盐湖的倒影，不是天象；放在「霞类」里只因为它几乎总跟火烧云一起出现。
- **火烧冰存疑**：本次检索未找到稳定用法，暂按「火烧云 + 冰晕」的临时合称收录，并在表内标注。
