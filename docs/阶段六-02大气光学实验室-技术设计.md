## 0. 定位与边界（先说清楚不该做什么）

- 这是一个**物理光学模拟器**，输入「冰晶类型/取向/大小 + 太阳位置 + 相机参数」，输出「天空中的晕相图」。
- **它不是天气预报**。页面上必须固定写明：模型假设、近似条件、已知偏差。
- **它不能碰现有评分与评分文案**；也不与 `/cross` 的模式云场混在一起展示（除非明确标注分层）。
- 与现有系统的唯一共享点：`sun.ts`（太阳位置）、相机/机位坐标、`data/` 下的静态缓存接口。

## 1. 模块划分（建议 `src/lib/optics/` + `tools/optics/`）

| 模块 | 职责 | 运行位置 |
|---|---|---|
| `crystal.ts` | 六棱柱冰晶几何：顶点/面、c 轴、面编号、P/B/D 对称操作 | 前后端可共用（无 DOM） |
| `trace.ts` | 几何光学光路追踪：入射面/出射面/折射率、偏转角、等价光路枚举 | 离线优先（CI/脚本） |
| `orientation.ts` | **取向分布采样**（见 §3，这里是历史 bug 高发区） | 离线 |
| `camera.ts` | 投影：rectilinear / fisheye；azimuth/pitch/roll/FOV → 屏幕坐标 | 前端 |
| `diffraction.ts` | 艾里斑 → 高斯近似 → 按 RGB 通道做模糊（见 §4） | 离线 + 前端 |
| `render.ts` | 把光路命中累积成强度图（或直接合成到照片） | 离线 |
| `fit.ts` | 用真实照片反推冰晶大小/取向（篇 8 的方法） | 工作流/人工 |

**算力策略**：光路追踪与百万条光线的累积放 CI/脚本，前端只加载预计算相图（小 PNG/强度图 + 元数据），
或在 WebWorker 里做低分辨率交互，避免主线程卡死。

## 2. 几何光学核心

### 2.1 冰晶模型

- 六方冰晶（ice Ih）：60° 棱柱，两种基本晶型：**片晶（plate）** 与 **柱晶（column）**。
- 折射率：黄光 `n=1.31`、红光 `n=1.307`（[R0] §4.1，原文明确数值；实际可按波长插值）。
- 最小偏向角 `δ_min` 由棱角与折射率决定；对 60° 棱、n=1.31 → **约 22°**（这正是 22° 晕的成因）。
- 取向族：随机取向（random）、片晶（plate，c 轴近似竖直）、柱晶（column，c 轴近似水平）、
  Parry（c 轴在水平面内、两个面保持水平）、Lowitz（c 轴在 30° 附近）。

### 2.2 需要支持的晕 + 其验证角度

| 现象 | 几何条件 | 验证目标（来自 [R0]） |
|---|---|---|
| 22° 日晕 | 柱晶随机取向，60° 棱两次折射 | 黄光半径 **21.8°**、红光 **21.6°**；太阳有限角径 → 观测半径 **−0.15°**；温度 −55°C vs −3°C **+0.15°** |
| 22° 幻日 | 片晶，光从竖直棱面进出 | 出现在 0°–55° 高度角；低太阳时位于 22° 处 |
| 环天顶弧 / 环地平弧 | 片晶，底面进出 | 出现高度角 **0°–32°** / **58°–90°** |
| 上/下切弧、外接日晕 | 柱晶 | 0°–35° / 35°–90° |
| 幻日环 | 片晶为主 | 0°–90° |
| 日柱 | 片晶，底面镜面反射 | 太阳高度角 <20° 易见；云底温度 −10~−25°C，DGZ −12~−18°C 最好 |
| 偕日弧 | **Parry**，侧面与地面恒 60° 反射 | 太阳像落在**顶角 120° 的圆锥**上（[R0] §4.3） |

> 上表的角度范围是"最可能出现的太阳高度角区间"，来自 [R0] 表 2.2；
> 实现后要用**光线追踪复现**这些区间（例如环天顶弧在 el>32° 时应基本消失）。

### 2.3 光路等价性

- 同一光学效果往往有多条内部反射光路等价（偕日弧：`5`、`1-4-2`、`4-8-6`、`5-7-8-3-5`）。
- 实现策略：先枚举面序列，用群论对称性（P/B/D）做等价类压缩，再只追踪代表路径。
- ⚠ **等价性的群论推导在外部知乎文章里，我们没读原文（W6）**：先按"枚举 + 对称性去重"的朴素方法实现，
  把"用群论压缩"作为优化项，不作为 v1 依赖。

## 3. 取向分布：这里有一个必须避开的历史 bug

[R0] §4.2 记录：旧版模拟器在**一维**上取高斯角再绕 z 轴旋转，导致 c 轴过度集中在天顶。
正确做法有两层：

1. **球面采样必须乘面积元**：`p_sphere(θ) ∝ p_distribution(θ)·sinθ`，
   否则在 θ→0 处出现概率奇点（物理上不对：受湍流扰动的片晶，总倾角在 0 附近概率趋近 0）。
2. **两个正交自由度各自的分布合成**：
   - 两个独立高斯 → 倾角大小 `|θ|` 服从**瑞利分布**；
   - 多个方差不同的高斯叠加（方差服从指数分布）→ **拉普拉斯分布**；
   - 实践结论（原文）：用拉普拉斯分布能同时得到"三角形幻日"与"不过度出现幻日环"的效果。

**验证方法（不依赖任何黑盒）**：写一个"浮板受随机冲击"的数值实验（泊松冲击 + 弹簧回复 + 粘滞阻尼），
积分稳定后统计 `|θ|` 分布，与瑞利/拉普拉斯/高斯拟合对比——这正是原文作者的验证方式，
我们可以独立复现，不抄代码。

## 4. 衍射模糊（波动的正确"糊"法）

[R0] §4.4 给出的可实现链条：

```
艾里斑第一暗环角半径  θ0 = 1.22·λ/d            d = 等效衍射孔径
高斯近似系数          σ = θ0 / 2.867           （1.336 = 3.83/2.867，原文最小二乘拟合结论）
像素半径              px = θ(rad或度) × (图像高度像素 / 垂直FOV)
```

必须遵守的三条：

1. **RGB 分通道**分别算 `λ=650/532/450nm` 的模糊核，再合成。否则锥晶幻日内侧的红色边缘做不出来。
2. **宽高比/FOV 近似**：多数设备是 rectilinear 投影，高斯核在画面边缘应变；v1 允许全图同一核，
   但必须在页面上标注"近似"。
3. **等效衍射孔径是粗糙近似**（原文自评，W8）：`d_diff ≈ (√2/2)·d_crystal`。
   这是可调参数，不要写死成"物理常数"。

**验证目标**（原文给的对照表，可直接当单测）：

| 冰晶加权平均半径 | 550nm 高斯核半径 |
|---|---|
| 5.65 µm | 1.677° |
| 9.58 µm | 0.990° |
| 12.47 µm | 0.760° |
| 15.73 µm | 0.603° |
| 21.59 µm | 0.439° |

> 这些数值本质是 `1.22λ/d/2.867` 的换算，用来检查我们的**单位与投影换算**有没有错。

## 5. 相机与对齐

- 相机参数：方位角（azimuth）、俯仰（pitch）、横滚（roll）、视场（FOV）、投影方式（rectilinear / fisheye）。
- 参考照片对齐：用已知角度特征（幻日到太阳的 22°、晕半径）反推 FOV/朝向，再叠加模拟。
- 验收：把模拟的 22° 晕叠到一张已知 FOV 的照片上，晕圈应落在 22° 处（误差 <0.5°）。

## 8. 风险清单

1. **物理过度简化**：等效孔径、(√2/2) 比例、全图同核，都是作者自评的粗略近似。
   → 页面上逐项标注；不宣称"物理精确"。
2. **取向分布未知**：真实卷云的取向分布没人测准；拉普拉斯只是经验拟合。
   → 提供参数面板，默认值来自原文经验，并标明"经验值"。
3. **版权**：原文图不能抄、不能改；冰晶谱数据集要核对许可。
4. **算力**：前端实时追踪不现实。→ 离线预计算 + 前端只做参数化挑选。
5. **概念风险**：模拟图很容易被误当成"今天天空会长这样"。
   → 固定文案 + 与天气页物理隔离（不同页面/不同入口）。

## 9. 实施顺序（建议，均需先交设计再写码）

1. **纯几何层**：`crystal.ts` + `trace.ts`，只算角度，不出图；用 22° 晕与偕日弧的解析值做单测。
2. **取向层**：`orientation.ts` + 浮板实验验证；把旧 bug 的正确做法写死在测试里（防回归）。
3. **衍射层**：`diffraction.ts` + 核半径单测（5 组数值）。
4. **渲染层**：离线生成相图，前端相机投影叠加；先只支持 22° 晕 + 幻日。
5. **扩张**：环天顶弧、外接日晕、偕日弧；再做"从照片反推冰晶大小"（篇 8 的流程）。

每一步的交付物：设计说明 + 数据需求 + 公式 + 验证记录 + 风险更新；
**没有通过验证的功能不展示给用户**。
