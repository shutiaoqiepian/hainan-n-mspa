# 阶段七-05 · RH 诊断「潜在云区」图层（任务书 P2 前半）

日期：2026-11-01

> 任务书 §3.1 要求：用相对湿度识别潜在饱和区、阈值可配置、并**明确区分**
> RH 诊断 / 云水 CLWMR / 云冰 ICMR / 总云量 TCDC。本轮把这一层补上。

## 1. 做了什么

- 新增图层开关「潜在云区 RH≥90%」（默认关），阈值可在 80/85/90/95% 之间切换；
- 画法：以 9 个模式层为准的**极淡横向底纹**（alpha 0.05–0.14，湿度越接近 100% 略实），
  放在云场**之下**，不抢真实云水的视觉优先级；
- 图例与免责声明都写明：**「潜在云区」是湿度诊断，不是模式云水/云冰**；
- 缺测处理：某一层 RH 缺测就不参与插值；两侧都缺测就跳过（不当 0、不当"干燥"）。

## 2. 为什么阈值要可配

"多少湿度算可能成云"没有唯一答案：模式分辨率、温度、气溶胶都会影响。
默认 90% 只是"高湿"的常用工程档位，**不是物理判据**；拖到 80% 会看到更宽的区域，
拖到 95% 只剩最湿的核。页面把三个档位都留给用户自己看。

## 3. 与其它云变量的关系（界面上的区分）

| 图层 | 含义 | 来源 |
|---|---|---|
| 潜在云区（新增） | RH ≥ 阈值 的湿度区域 | GFS RH（9 层） |
| 云水 CLWMR | 模式里的液态水 | GFS 原生 |
| 云冰 ICMR | 模式里的冰晶 | GFS 原生 |
| 总云量 TCDC | 模式云分数（0–100%） | GFS 原生 |
| Open-Meteo 估算云 | RH 诊断出的云量 | 对照源，页面已单独标注 |

四者**不混算**：阈值图层只画底色，不参与任何"云"的着色、也不进 tooltip 的云水读数。

## 4. 已知限制

1. RH 是模式层上的值，垂直分辨率只有 9 层（层距 0.5–2.5 km），看不到薄层结构。
2. 高湿 ≠ 有云：RH 100% 也可能没有云水（模式里水物质需要微物理过程产生）；
   低湿也可能有云（云在更细的尺度上）。所以这一层**只做提示，不做判据**。
3. 阈值是工程选择，不是物理定律；不同季节/地区最优阈值可能不同（待 30 天样本验证）。
4. 与卫星云顶高度对照时，请注意卫星看的是"有云顶反演的像素"，不是湿度。
