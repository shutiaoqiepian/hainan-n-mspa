# 阶段八-02 · 降水区域表达（任务书 P4 第一半）

日期：2026-11-01

> 任务书 §3.6 要求：用**真实降水率变量**生成圆点、按强度分档、标明单位、
> 区分「降水率」与「降水概率」、缺测不得显示为无降水。本轮把降水接进 `/cross`。

## 1. 数据：新增 GFS PRATE 变量

| 项 | 内容 |
|---|---|
| 变量 | GFS `PRATE`（地面降水率，kg m⁻² s⁻¹）→ 换算 `mm/h = PRATE × 3600` |
| 获取方式 | `filter_gfs_0p25.pl` 单独一次请求（`lev_*_mb` 只覆盖气压层，地面场要单独指定） |
| 落盘位置 | 每个采样点每一行追加 `rainMmH`（与层无关，但为不改变数据形状而重复） |
| 缺测 | `null`，**绝不写 0**。前端画空心 `?` |
| 体积 | 645.7 KB → **699.7 KB**（8 机位 × 160 剖面） |

实测（2026-11-01 08Z 起报）：本时段海南全域降水率 0–0.84 mm/h，绝大多数为 0——
这正是日落预报里"没有降水"的正常情况，不是缺测。

## 2. 界面

- 工具栏新增「降水」开关（**默认开**）；
- 画法：每个 12.5 km 采样点在地面上方画一列圆点，点的大小/数量按 4 档（0.02–0.15 / 0.15–0.35 /
  0.35–0.6 / ≥0.6 mm/h）递增；点堆叠 0.6 km 表示"这一列空气在下雨"，**不是云层高度**；
- 缺测画空心 `?`；
- 图例写明「降水率（地面 mm/h，不是概率；? = 缺测）」。

> 分档按本区域实际量级定的（0–0.84 mm/h），不是通用气象分级——
> 首版用 0.5/2/5 mm/h 分档时，本区域所有降水都落在最低档，看起来像"没画"。

## 3. 没做：彩虹几何

任务书要求彩虹需要「太阳方位 + 观测者 + 降水区域」的三维关系，二维剖面表达不了。
本轮**没有**做彩虹判断，也没有在界面上给任何"可能有彩虹"的暗示——
按硬约束，拿不到几何条件就不许宣称。

## 4. 测试

`node tools/test-rain.mjs`（19 项）：8 机位 × 160 剖面逐字段校验

- `levelFields` 必须含 `rainMmH` 且下标正确（= 最后一位，10）；
- 所有降水值在 0–200 mm/h；
- **造一条全 null 的最小 section，验证读出来仍是 null 而不是 0**。

再加上 `verify_cross.py` 新校验（字段数 11、降水率范围）。
