## 产出 2：五个验收问题（逐条作答）

### Q1. 文献 #1（CMA-BJ）说"预报有多不准"，它怎么导致要用 `pow(raw, 1.8)`？

**答**：文献 #1 是 CMA-BJ 系统总云量预报的检验评估（A 级期刊《气象》2024），核心数字是 **1 天时效的真实技巧评分 TSS 仅 0.47，且有技巧上限 48–72 小时**。意思是：**即使是最好的模式，1 天后的云量预报也只有约一半的"真本事"，超过 2–3 天基本没有技巧。**

这直接导向两个设计：① 因为云量本身预报不准，分数不能线性放大——`raw`（五个因子连乘的 0~1 值）用 **1.8 次方压缩**，把本就偏高的中段分数往下压，配合"宁可漏报不可误报"（红线 2）；② 时效越远，分数打越多折扣。

**关键点**（也是 DSH 反复强调的）：文献 #1 给的是"**预报有多不准**"，**不是**"火烧云概率模型"。1.8 次方是"用保守压缩对冲云量预报的低技巧"，不是从霞光物理推导出来的。

### Q2. 为什么高云 0% 时不能硬性归零？

**答**：依据文献 #2（MetCoOp/Met Norway, 2012, *Verification of cloud forecasts*，A 级）。它指出 **ECMWF、AROME 等模式系统性高估"无云"的出现频率**——"报晴 ≠ 真晴"，模式说高云 0% 时，实际天空常常还是有薄云的。

所以如果 `fHigh` 在 `h < 8` 时**硬性 return 0**，就会把"模式误报的晴"当成"真晴"一刀斩杀——而实际上那些日子是有薄云、能出霞的。这就是为什么 `fHigh` 要在低端**保留缓坡**而不是硬归零。

（注：这一点和用户反馈"少云/晴天报不烧"直接相关——但要注意，文献 #2 支持的是"**低端缓坡**"，即高云 0~8% 不该是 0 而该有个小值；它**不直接支持**"天空霞"这个更大的概念，天空霞还需要独立的判据。）

### Q3. `α=0.6`、RH `92/85/76/66` 是 A 级文献值还是本站反推值？

**答**：**本站反推值（D 级），无观测标定。** 都在 `research/README.md` 第四节 D 级表里：
- `α=0.6`：由 `tools/ab-midcloud.mjs` 在"全站平均上浮 <1 分"硬约束下反推（扫 0.4/0.6/0.8，0.8 上浮 +1.12 超门槛，0.6 上浮 +0.54 达标）。
- RH `92/85/76/66`：是"无光学厚度数据时的标准替代做法"，但**未本地验证**，刻意往不透明方向取整。

两者都是 ❌ 无观测标定，属于台账 `midcloud-calibrate` 等数据。**任何界面措辞只能说"当前取值/已计入评分"，不能说"准确率"。**

### Q4. 想解决"分数太挤"，该动压缩指数还是上游画布？为什么？

**答**：**动上游画布（加入新信号），不动压缩指数。**

证据（我自己的 `_tmp-exp-scan.mjs` 实测）：A 级 220 条样本里 **144 条（65.5%）是 0 分**，0 分 = `raw=0` = 高云画布 `h≤0`。而 `score = 100·raw^1.8`，**0 的任何次方还是 0**——所以把 1.8 调小，对这 65.5% 的样本**完全无效**。剩下 34% 非零样本的 spread，全部转化成了误报率上升（2.3%→8.5%），命中几乎不涨（1→2）。**纯亏。**

所以正确的杠杆是**上游画布**——要么给"高云少但天干净"的样本加一个新信号（=天空霞方向），要么让中云/其他层补画布（已有 `midLift`）。这是 `ALGORITHM-COLLAB.md` §1.3 里"杠杆②（加入新信号）"，而不是"杠杆④（改指数）"。

### Q5. 天空霞（clear-sky glow）当前有几条 A 级依据？

**答**：**0 条。** 见产出 1 的对照表——分类、判据、阈值全是 C/D 级；仅有的 A 级（Bohren & Huffman #12、Petty #13）只支撑散射原理，不支撑"晴空能不能烧"的判据。

## 产出 3：一句话结论

> **天空霞方向立项，A 级依据有 0 条，所以它现在只能算 C 级（经验/启发式）。**
> 要在界面上说"准确率"，还差：**A 级样本（METAR 配对）的观测标定**——即用回填的"实际烧没烧"结果，对天空霞的判据（AOD 甜区、太阳高度窗口、云量下限）做一次真实配对验证，证明"触发天空霞 → 实际出霞"的命中率，且误报率不劣于 v1。在拿到这个之前，只能叫"环境符合度/当前取值"，不能叫概率或准确率。

## 附：我学到、并要纠正自己的三点

1. **我上一版 `sky-glow-literature.md` 把来源等级标高了**。福建气象局、Mount Washington、中国气象局、Vesper Sky、央广网——全是 C 级（科普/观测站博客/商业产品/民间经验），我当时把它们当"权威背书"用，这是错的。C 级只能当启发式，不能当"科学依据"。已在本表纠正。

2. **Bohren & Huffman / Petty 是 A 级，但作用有限**。它们回答"为什么天是红的"（瑞利散射 λ⁻⁴ + 米散射 + airmass 光程），是天空霞的**原理底座**，但**给不出"晴空能不能烧、AOD 阈值多少"的判据**。不能拿它们去"证明"天空霞判据是对的——那属于"拿 A 级教材去给 D 级经验值背书"，是偷换等级。

3. **天空霞可以做的正确姿势**：做成 v2 实验版（可选开关、只增不减、不传即逐位一致），用 A 级样本算 v2a（要薄云）/ v2b（纯晴也给分）两个变体的误报率，**让数据决定触发条件**，而不是等主人拍一个可能永远等不到的产品答案。
