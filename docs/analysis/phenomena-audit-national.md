# 天象词条预测合理性核查（全国口径）

核查对象：`src/data/forecast/phenomena.ts` 全部 69 条词条的 `when`（说明）与 `match`（判据），
兼及 `scoring.ts` 中被判据调用的派生量（crep / pillar / rainbow / clarity）。
核查维度：气象要素、时空尺度、季节气候背景、物理机制四者是否自洽。
核查日期：2026-11-28。

## 修订记录（2026-11-28 夜，同日核查后修复）

下面 12 处已改到代码里，审计时的判断保留在正文，便于回溯我当时为什么这么判。

### 一、"能见度单位错"这个结论要更正——根因比单位更深

原判断是"接口返回米、判据按千米用"。实测三个模式后要补一句：
**ECMWF 与 ICON 的 `visibility` 24 小时全为 null，只有 GFS 有值**（24140 m）。而缓存构建与前端剖面请求都只挂 `ecmwf_ifs025`，
所以缓存里这一列一直是空的。两个错叠在一起：缓存路径下判据永远"缺测"，实时回退路径下变成"16400 km"。

改法：把 `visibility` 挪进多模式天气请求（GFS 有值会被 `avg()` 取到）；入口统一米→千米；
剖面覆写改成"有值才覆盖"。重建海南缓存后实测 7540–24140 m → 7.5–24.1 km。

### 二、结构性不可达（5 处）

| 条目 | 原问题 | 改法 |
| --- | --- | --- |
| 彩虹 / 双彩虹 | `rainbowOf` 要太阳高度 3–42°，但传入的是日落时刻（el≈0），恒 0 | 向前回溯到当天最接近 el=25° 的整点再评估；实测 el=25°、pop 60% 出 80 分 |
| 日柱 | `pillarOf` 乘 0.6，满值 60，判据却写 ≥70 | 阈值改 55/35，与 `pillarLabel` 对齐 |
| 其它时段 | 只过粗门不跑判据，且用日落上下文判白天词条（要 el 15–32°），必然全空；粗门过后又固定取前 2 条 | 白天/夜间各取代表小时重建上下文，真跑 `match`，按命中强度排序 |
| 夜间 6 条 | 判据全是 `() => 0` | 银河、星轨、月晕、月华给真判据；夜光云、极光、月虹仍保留 0（缺地磁/中间层/月相） |
| 火烧冰 | 要 t≤-25℃（6000 m 标准大气约 -24℃，低纬更暖）+ 300 hPa 云量≥30%（全年 0–4 小时） | 温度门槛改 -20℃，补 `c.high` 退路；`local` 由"常见"降为"少见" |

### 三、分类与几何错误（4 处）

- **反云隙光**：`faceOff` 只表示"偏离太阳约 37°"，反日点要 180°。新增 `antiFace`（把太阳方位 +180° 当虚拟太阳再算一次 `faceMatch`），判据改 `antiFace ≥ 0.72`（约 68° 以内）。
- **宝光**：从"冰晶光学"归到"大气"——它是水滴背向散射，和彩虹同族。
- **雨幡**：`key: 'velum'` 是术语错误（velum 是幞状云），改为 `virga`；中文名由"幡状云"改为规范名"雨幡"。
- **月晕/月华**：原一条混了冰晶折射（22° 晕、幻月）与水滴衍射（数度华）。拆成 `moonhalo` 与 `mooncorona` 两条，词库 69→70。

### 四、阈值与前提（3 处）

- **维纳斯带**：太阳高度上限 +2°→-0.5°。地影是地球挡光投在大气里的暗带，太阳还在地平线上时它尚未成形。
- **46° 晕**：去掉 `el ≥ 20`。角半径固定 46°，太阳高度只决定能看到哪段弧，不决定能否出现。
- **蓝调**：下限 -12°→-8°。原区间与"日落后 15–35 分钟"文案对不上。

### 五、补前提（3 处）

- **舞台光 / 云影 / 天光**：加 `sunEl > -1`。三者都要直射光，`crep` 在日落后仍留分数，会误报"天黑透了还有光斑"。
- **雨层云**：不只看 700 hPa 的 Ns，补"低云≥70% + RH≥90% + pop≥60"。雨层云云底 0.5–2 km，单判 3 km 那层会漏掉云底压到地面的典型个例。
- **滚轴云**：加 `cape ≥ 1000`。缺阵风锋/风切变数据，单看"低云多+降水概率高"等于每个阴雨天都报。

### 六、口径（2 处，未做"假全国化"）

- 白天 5 条的 `hours` 从写死钟点改为"太阳高度 X° 时（海口约 …）"——判据用的是太阳高度，钟点随纬度季节变，写死等于把海南口径当全国口径发。
- 词典页与徽章 `title` 补"海南口径"说明：冰晶类在高纬更多、极光与夜光云相反。

### 七、仍写死 `() => 0` 的 7 条（数据不足，不编）

`fluctus`（KH 波，缺高分辨率风切变）、`lenticular` / `marble`（荚状云/山帽云，缺地形与层结剖面）、`glory`（宝光，缺云雾方位）、`noctilucent`（夜光云，缺中间层）、`aurora`（极光，缺地磁）、`moonbow`（月虹，缺月相）。这 7 条在词典可查，但不参与预测。

## 0. 结论摘要

- 69 条中：**合理 22 条、存疑 34 条、不合理 13 条**。
- 最重的三类问题不是"某条判据偏松"，而是**结构性不可达**：
  1. 能见度单位错（接口返回米，判据按千米用），使晨雾、雾虹永不命中，通透/云隙光/日柱/鲜亮度的能见度因子恒为 1；
  2. 评估时刻固定在日出/日落（太阳高度≈0），使彩虹、双彩虹永不命中；
  3. 云层判据取"最高有云层且高度≥6000 m"，而全国 500 hPa 高度最高 5936 m，300 hPa 云量≥30% 全年仅 0–4 小时，使火烧冰（t≤-25℃ 且云量≥30%）近乎不可达。
- **至少 18 条词条在任何天气下都不会作为"预测提示"出现**（词典仍可查）：
  10 条判据恒 0，彩虹/双彩虹、晨雾/雾虹、火烧冰各 1–2 条，另有幻日、46°晕、环地平弧被"白天组只取 2 条"的排序永久压住。
- **全国口径错配**：`local` 评级注明"按海南一年里能碰到几回算"，`hours` 注明"按海口北纬约 20°"给的经验值；
  但站点覆盖 224 个机位、18.22°–53.47°N、34 个省级区划。同一评级与同一钟点无法同时适用于三亚与漠河。
  例：环地平弧需太阳≥58°，三亚一年 258 天满足、广州 231 天、北京 143 天、漠河只有 48 天（且仅正午前后约 1 小时）。

### 1.3 口径

- 一条词条只在一个时刻被评估：该机位的日出或日落（`api.ts` 的 `phenoCtx()` 取 `o.sun.el`，日落时刻 el≈0）。

- `local` 是海南口径；`hours` 是海口口径。两者都随详情面板展示到全国机位。

## 2. 判定分布与系统性问题

### 2.1 分布

| 判定 | 条数 | 含义 |
| --- | --- | --- |
| 合理 | 22 | 机制、要素、阈值自洽，可作为近似判据 |
| 存疑 | 34 | 机制成立，但缺关键要素、阈值任意、尺度不匹配或文案与代码不一致 |
| 不合理 | 13 | 判据在物理上不能代表该现象，或结构性不可达、或概念混装 |

### 2.2 六类系统性问题

1. **单位错误（实现层，影响最大）**
   `visibility` 接口单位为米（实测 16400 m），`m.vis` 未换算；`SpotPanel.vue` 展示时除以 1000，反证内部是米。
   而 `scoring.ts` 与 `phenomena.ts` 的阈值 25/20/15/8/5/2 全部按千米写。
   后果：晨雾 `vis<=5`、雾虹 `vis<=2` 永不成立；绿闪 `vis>=25` 恒成立；
   `clarityOf`/`crepuscularOf`/`pillarOf`/`vividnessOf` 的能见度因子恒为 1；`interpret.ts` 的"能见度 N km"永不触发。

2. **评估时刻错配**
   彩虹需要太阳 3°–42°，但共用上下文固定在日落 el≈0，`rainbowOf` 先返回 0；彩虹又是 `scope: any`，不在"白天"组里，
   于是彩虹与双彩虹既不在此刻出现，也不在其它时段出现；决策卡的"彩虹"指数同理恒为 0。

3. **层位与阈值不可达**
   火烧冰要求"高度≥6000 m 且 t≤-25℃ 且云量≥30%"；全国 500 hPa 最高 5936 m，300 hPa 云量≥30% 仅 0–4 h/年 → 0/8784。
   日柱 `pillar>=70` 不可达：`pillarOf` 最大值为 100×0.6=60。

4. **要素缺失**
   云相态与冰晶取向（晕族）、风切变（迭浪云/滚轴云/糙面云/荚状云）、海拔与地表类型（云海/宝光）、
   潮汐与风速（天空之镜/倒影/金色光路）、月相与银心高度（银河/月虹/月晕）、光害（银河/星轨）、
   边界层气溶胶廓线（污烧/通透）。这些不是"阈值调一调"能解决的。

5. **时空尺度错配**
   格点 726 km²、逐小时。云缝、云底 600 m、能见度 2 km、KH 波（百米级）、幞状云（分钟级）、
   绿闪（1–2 秒）都在格点与步长之下。判据只能给出"气候概率"，不能给出"此刻头顶有没有"。

6. **全国口径错配**
   `local` 与 `hours` 是海南专用，却随 224 个机位展示。漠河 53.47°N 的太阳高度窗口、钻石尘、夜光云、极光，
   与三亚 18.3°N 完全不同；同一枚"几乎不可能"徽章在漠河是错的。

## 4. 分维度归并

### 4.1 气象要素

- 齐备且与机制对应的：霞族（1–12）、云种（20/23/26/51）、彩虹族（34/59 的分子量，不是判据）、通透（65）。
- 用代理量顶替的：日晕族（湿度顶替冰晶）、低云压顶（LCL 顶替云底）、雨层云（700 hPa 顶替云底）、
  晨雾（RH+能见度顶替逆温与风）、云海（2 m RH 顶替云层湿度）。
- 完全缺要素的：风切变（24/25/27/30/54）、云相态（18/19/46–49）、海拔（27/35/44/62）、
  地表与潮汐（39/40/42）、月相（45/57/60）、光害（57/58）、边界层气溶胶（7/65）。

### 4.2 时空尺度

- 可以按格点+小时判的：大尺度云量、气溶胶柱、太阳高度、降水概率。对应霞族、通透、黄金/蓝调。
- 尺度不符的：云缝（13/15/17/43/67）、云底 600 m（31）、雾（61/68）、KH 波（25）、幞状云（28）、
  乳状云（29）、滚轴云（54）、绿闪（38）。这些只能给"今天这类天气下值得留意"，不能给"此刻会有"。

### 4.3 季节气候背景

- 与季节强相关的词条，判据里没有任何季节约束：排骨云（冷空气，冬春）、云海（冬春逆温）、
  晨雾（冬春辐射雾）、银河（银心 3–10 月）、环地平弧（夏半年正午）、火烧冰（北方冬季）。
- 评级与季节冲突的：火烧冰标"常见"但当月不可达；环地平弧标"几乎不可能"而三亚一年 258 天太阳条件满足；
  夜光云/极光/钻石尘标"几乎不可能"但在漠河成立。

### 4.4 物理机制

- 机制描述正确、判据不对应的：舞台光、云影、天光（缺 el>0）；反云隙光（方位角门槛错）；
  滚轴云（缺阵风锋）；雨幡（名称与机制不符）；宝光（归组错）；月晕（与月华混装）。
- 机制本身仍有争议、不宜写死的：糙面云（成因未定）、乳状云（负浮力/重力波两种解释）。

## 5. 可修与不可修

### 5.1 只改判据/文案即可修（不动词条、不引新数据）

| 问题 | 改法 |
| --- | --- |
| 能见度单位 | `m.vis` 统一换算为 km（或在阈值处除以 1000）；`interpret.ts` 同步 |
| 彩虹/双彩虹不可达 | 改为在"白天"组按正午前后评估，或在 detail 里另算一次 el=20° 的彩虹指数 |
| 日柱 70 不可达 | 阈值改 55（`pillarOf` 上限 60），或去掉 ×0.6 后重标定 |
| 舞台光/云影/天光 | 判据加 `el > 0` |
| 反云隙光 | 用反日点角距（>140°）替代 `faceOff`（>37°） |
| 维纳斯带 | el 上限改 0，并要求反日方位低云≤25 |
| 火烧冰 | 层位门槛从 6000 m 改 5000 m，或直接改评级为"罕见" |
| 白天/夜间组固定两条 | `matchOtherTimes` 改为按当天 `match` 值排序，或每组限额 3 条并轮换 |
| 小烧 48–82 / 日柱 -8~+5 / 日晕湿度 / 蓝调 -12 | 文案与代码对齐 |

### 5.2 必须补数据才能修

- 云相态与云光学厚度：晕族、卷层云、火烧冰的成立前提。
- 冰晶取向：幻日、环天顶弧、环地平弧、幻日环、46° 晕。任何业务模式都不给，只能靠卫星/现场。
- 风切变与阵风锋：迭浪云、滚轴云、糙面云、荚状云、排骨云。
- 机位海拔与地表类型：云海、宝光、天空之镜、倒影、金色光路。
- 潮汐（Open-Meteo Marine 可取）与 10 m 风（已在原始数据里，只是没进判据）。
- 月相与银心高度（可本地天文计算，不需外部数据）。
- 光害底图：银河、星轨。
- 本地历史实拍/观测统计：所有 `local` 评级的分母。

## 6. 资料缺口（据此不能下的结论）

1. **各机位历史出现频率**：只有 2024 一年的模式再预报，没有人工观测/实拍台账，无法给"一年几次"的可靠分母。
   现有 `local` 评级是经验值，本次核查只能指出它与纬度/季节的冲突，不能给出替代数值。
2. **224 个机位逐点气候**：本次只取 6 个纬度带 + 海口，不能代表全部机位（尤其高原、盆地、海岸）。
3. **云相态与冰晶**：没有卫星云相态、云光学厚度、激光雷达，无法验证"卷层云里到底有没有冰晶"。
4. **次网格结构**：没有雷达/卫星云图，无法验证云缝、云底、雾、KH 波的实际分布。
5. **实测验证**：本次所有频率均来自模式再预报，不能当作观测频率；判据阈值的最终标定需要实拍样本。

## 7. 建议的最小改动集（按影响排序）

1. 修能见度单位（1 行换算），恢复晨雾、雾虹、通透、云隙光、日柱、鲜亮度里的能见度因子。
2. 彩虹改在白天评估（或单独算一次），恢复决策卡的"彩虹"指数。
3. 日柱阈值 70→55。
4. 舞台光、云影、天光加 `el>0`；反云隙光改用反日点角距；维纳斯带 el 上限改 0。
5. `matchOtherTimes` 改为按当天 `match` 排序，避免"环天顶弧+日晕""银河+月晕"固定两条。
6. `local` 与 `hours` 加"仅海南"限定，或按纬度带给 3 套评级/钟点（华南、华中、华北/东北）。
7. 火烧冰改判据或改评级。

以上 1–5 是判据/文案层，不动词条；6–7 涉及产品口径，需要先定"全国一套"还是"分区域几套"。
