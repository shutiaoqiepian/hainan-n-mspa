> **已经可以自洽解释**：表 1.3 的数值 = 2×√(2Rh)。
> 推导（本文补充，非原文）：在地球切线处把光线近似成抛物线 `z = s²/(2R)`，
> 则高度 h 上被照到的水平半宽 `|s| ≤ √(2Rh)`，**全宽 = 2√(2Rh)**。
> 这正好复现表 1.3/1.4。但原文公式在图片里，**"霞光深入距离"的确切几何定义仍属待核实**。

**视线高度公式**（正文明确）：`h ≈ d·tan(α) + d²/(2R)`，其中 d 为球面水平距离、α 为视线高度角；
`α=0` 时退化为 `h = d²/(2R)`。正文声称 1000 km / 100 km 高度内误差 < 2%。

**日落线速度**（附录表，km/分钟，可查）：20°N 在 11/15 为 20.5；海南（18–19°N）11 月约 **20.6 km/min**。
极端案例：上海 21 km/min、伊春 18 km/min。

**AOD 观感分级**（表 2.3）：0–0.1 水晶天 / 0.1–0.2 湛蓝 / 0.2–0.3 较蓝 / 0.3–0.5 普通 /
0.5–0.8 有霾 / >0.8 污烧。（与项目 `AOD_BANDS` 一致，说明我们现在的分级不是自己编的。）

**气溶胶消光垂直分布**：`σ_a(z) = σ_a(0)·e^(−z/H)`，`AOD = σ_a(0)·H`。
**等效地表高度**（正文给了闭式解与查表）：
`z_eff = H·ln(σ_a(0)/σ_th) = H·ln(AOD/(H·σ_th))`，原文取 `σ_th = 0.02 km⁻¹`（"消光系数高于它光线无法穿过"）。
**用表 4.1 逐点反算验证过**：H=0.5、AOD=0.15 → 1.354 km（表 1.35）；H=1.0 → 2.015（表 2.01）；
H=2.0 → 2.65（表 2.64）。✅ 公式与数值自洽，可以直接进产品。
用途：**等效云底高度 = 云底 − z_eff**，这是"气溶胶消光修正云底"的工程实现。

### 1.2 几何模型（正文文字结论，公式在图片）

- 典型火烧云 = 单层、水平、边界清晰、云下无遮挡；**阳光从云边界下方照到云底**。
- **火烧云三角**（图 1.15）：近边界光线经过云边界，远边界光线与地表相切；
  两者之间即"何时/何地能看到火烧云"。可读出的结论：
  - 平底层状云的火烧云**只出现在日落后 / 日出前**；
  - 云底越高，可出现的范围越大；
  - 越靠近云边界，持续时间越长；远离边界则开始/结束都更晚（晚霞）；
  - 即使本地看不到云边界，也可能有火烧云（边界远）。
- 对流云模型：云顶越高、持续时间越长。
- 云洞漏光：云洞大小与云底高度共同决定最长持续时间；中云云洞还需要满足最小云洞长度条件
  （**条件公式在图片里，待核实**）。

### 1.3 光谱与消光（正文可读，公式在图片）

- 光学厚度定义 `τ = −ln(I/I0)`、`τ = ∫σ_ext ds`、能见度经验式 `V ≈ 3.912/σ_ext(550nm)`。
- 瑞利散射 `σ_R ∝ λ⁻⁴`；米散射（气溶胶/云滴）波长依赖弱，实测指数在 0.5–2 之间，典型取 1。
- **火烧云为什么红**：瑞利散射波长选择性强 → 颜色纯度高、饱和；气溶胶米散射选择性弱 →
  颜色发灰、饱和度低。**所以"光路上游的中层气溶胶"比"本地气溶胶"更关键**。
- 定性结论（可直接变成产品文案/规则）：
  - 云底越高，颜色变化越全（金黄→橘红）；云底低只有橘红；
  - 同云底高度时，云边界越远越红；
  - 低云不适合形成火烧云，除范围窄外还有气溶胶消光；
  - "颜色最红"的两种条件：大气通透 + 阳光穿低层大气；或中层存在 σ_a ≈ 0.01–0.02 km⁻¹ 的薄气溶胶层。
  - 亮度经验阈值：入射强度的 1/几 ~ 1/几十 → 明亮；1/几十~1/几百 → 闷烧；
    < 1/1000 观赏价值低；< 1/5000 基本看不到。

## 3. 火烧云预报教程章节四（实战 + 附录查表）

### 3.1 预报流程（可拆成产品里的"解释链"）

典型云况 5 步：① 拿日落方位的大气截面 + 沿线 AOD；② 判断是否典型云况，读云底高度并做气溶胶等效云底修正；
③ 套几何模型判断能否照到本地云底，算持续时间与高度角；④ 看探空判断云属与连带天象；⑤ 估不确定性。

非典型云况：先分类（高云漏光 / 中云漏光 / 对流云 / 一般复杂），**前两类与对流云"不支持基于模式的精确预报"**，
只能靠卫星云图实况外推；一般复杂云况可用"平移抛物线"通用法。

### 3.2 不确定性三来源（可直接做成"预报失败归因"分类）

1. **云量/云厚不确定性**：探空上露点与温度没贴合、云层薄 → 模式略微偏差就没云。
2. **云边界位置不确定性**：取决于湿度梯度（100 km 缓降 vs 1 km 陡降）、云边界**沿日落方向的风速分量**
   （<15 m/s 小、15–30 m/s 大、>30 m/s 很大）、云边界与太阳方位夹角（<10° 需特别警惕）。
3. **其他方向杂云 / 落幡遮挡**：会在剖面上表现为"云底钟乳石状倒三角"。

## 4. 冰晕与冰晶光学（篇 4/5/9/10 + 6/7/8）

### 4.1 22 度晕（篇 9，全是可引用数值）

- 六角柱状冰晶两个侧面折射，最小偏向角 ≈22°，内红外紫。
- **黄光 n=1.31 → 半径 21.8°；红光 n=1.307 → 21.6°**。
- 太阳不是点光源（角直径 ≈0.5°）→ 观测半径**减小约 0.15°**。
- 温度依赖：**−55°C 时半径比 −3°C 时大约 0.15°**；气压影响可忽略。
- 偏振度仅约 4%；双折射导致两个偏振晕环错开 **0.11°**（可被偏振镜看到跳变）。

### 4.2 冰晕模拟的历史 bug（篇 10）——做光学实验室必须避开

- 旧版（HaloSim ≤3.6.1 / HaloRay ≤4.1.0 / HaloPoint ≤2.0）Plate 取向采样：
  先在**一个自由度**上取高斯角，再绕 z 轴旋转 → 不等于二维高斯。
- 正确做法：球面上采样必须乘面积元 `p_sphere(θ) ∝ p(θ)·sin θ`；
  两个独立高斯分量合成 → `|θ|` 服从**瑞利分布**；多个高斯叠加（方差服从指数分布）→ **拉普拉斯分布**。
- 物理验证：浮板受随机冲击的数值实验显示，`|θ|` 在 0 附近概率**趋近 0**，峰值在 >0 处。
- 结论：**只有 Lumice ≥4.1.13 在数学上正确**；做实验室时取向分布必须按此实现。

### 4.3 偕日弧（篇 5）

- Parry 取向冰晶的侧面与地面夹角恒为 60°，反射太阳 → 太阳的像落在**顶角 120° 的圆锥**上，
  与天球交线即偕日弧。
- 等效光路（可复用做光路等价类校验）：`5`、`1-4-2`、`4-8-6`、`5-7-8-3-5`。
- 篇 4 的在线工具是"给出路径长度 1–8 + 对称性（P/B/D）→ 输出等价路径"的计算器；
  其群论推导在知乎外链，**待核实**。

### 4.4 冰晕合成工艺（篇 6/7）与衍射（篇 8）

- 合成思路（篇 6）：把冰晕看作「散射相函数」的篡改：
  `亮度 ≈ 到达该点的光照 × 该点散射系数(相函数) × 回程透光率`；用背景卷云提供"杂乱相函数"，
  用模拟图提供"高质量冰晶相函数"，做高频分离后叠加。
- 工艺（篇 7）：通道混合放大云/非云对比 → 多次高斯模糊相减取高频 → 加权得"冰晶质量掩码" →
  正片叠底 + 滤色 → 按衍射量做高斯模糊 → AIGC 修补细节。
- 衍射（篇 8，**核心公式**）：
  - 艾里斑第一暗环角半径 `θ0 = 1.22·λ/d`（d = 孔径/冰晶等效衍射直径）。
  - 艾里斑主瓣可用高斯近似，**最小二乘拟合得 σ/R_airy = 3.83/1.336 = 2.867**。
  - 换算像素：`像素半径 = 角度 × (垂直FOV / 图像高度像素)`；**RGB 三通道要分别算、分别模糊**，
    否则锥晶幻日内侧的红色边缘出不来。
  - 等效衍射直径：假设 c/a=1 正六棱柱，侧面投影面积的一半 → `d_diff ≈ (√2/2)·冰晶直径`（作者自称粗糙，**待核实**）。
  - 冰晶谱数据集：ACRIDICON/CONTRAST/ATTREX/POSIDON/STRATOLIM 汇总，DOI `10.34730/9EF25DADB84F4E7D9E0281CCB4086A3B`；
    原文给出分位区间 → 550nm 高斯核半径：5.65 µm→1.677°、9.58→0.990°、12.47→0.760°、15.73→0.603°、21.59→0.439°。

### 风险清单（按严重程度）

1. **概念混淆风险**：把"几何上被照亮"说成"一定会烧"。原文反复强调模式云量/边界的偏差会让结论翻车。
   → 产品文案必须区分"几何可见"与"云况可信"，并给不确定性等级。
2. **公式未核实风险**：几何公式、云洞条件、卷云透过率判据都只在图片里。
   → 在核对图片/复算之前，**不写进生产代码**；先用可验证的数值（表 1.3、3 个案例）反推校验。
3. **版权风险**：原文图/照片版权归作者；我们不能直接抄图或照片。
   → 只借鉴方法与数值，自绘示意图；数据集（冰晶谱）有 DOI 与许可，使用时注明。
4. **过度承诺风险**：光学实验室是"模拟"，不能当预报。
   → 与 `/cross` 一样，页面上必须写明模型假设与局限。
5. **算力风险**：光路追踪 + 每像素合成在前端跑会很重。
   → 先离线/CI 生成，前端只展示；或 WebWorker + 降采样。
