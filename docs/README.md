## 文档维护约定

1. **活文档只有 4 份**：`AGENTS.md`、`交接文档.md`、`README.md`、`使用说明.md`（+ 本索引）。
   改代码导致行为变化时，**优先更新这 4 份**。
2. `docs/阶段X-YY-*.md` 是**当时的事实记录**，历史数字过时是正常的，**不要改**——
   要纠正现状，去更新交接文档对应章节。
3. 新增专项文档时，**在本索引第 1 层加一行**（文档 + 规模 + 什么时候读），否则下一个 AI 找不到它。
4. 任何"过时/被推翻"的旧文档，移到 `docs/archive/` 并在第 2 层登记，不要留在根目录。
