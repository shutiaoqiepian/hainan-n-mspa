## 2. 公式记录表（8 项 × 8 要素）

> 记号：R=6371 km（地球半径）、`h_CB` 云底高度（km）、`l` 沿日落方向的水平距离（km）、
> `t` 相对「云边界处日落」的时间（min，正=日落后）、`v` 日落线速度（km/min）、
> `h_a` 气溶胶标高（km）、`AOD` 550nm 气溶胶光学厚度（无量纲）。

### F1 抛物线近似（原文图 image42）

| 项 | 内容 |
|---|---|
| 表达式 | `h(l) ≈ l² / (2R)` |
| 变量/单位 | l[km]、R[km]、h[km] |
| 适用条件 | 近地表、小角度（l ≪ R）；对 l≲1000 km 误差可忽略 |
| 出处 | 章节一 §1.2.1 图 1.10–1.12，image42 |
| 独立实现 | `farRayHeight(l,t,v)` 的特例（t=0） |
| 数值验证 | 与 `h ≈ l·tanφ + l²/(2R)` 在 φ=0 时一致；量纲 [km] |
| 近似边界 | 对流层内 h≤18 km、l≤1000 km 时误差 <2%（原文表述）；本文用它只为几何换算 |

### F2 视线高度（原文图 image136）

| 项 | 内容 |
|---|---|
| 表达式 | `h(l) ≈ l·tanφ + l²/(2R)`，φ=视线高度角 |
| 变量/单位 | φ[°或 rad]、l[km]、h[km] |
| 适用条件 | 1000 km / 100 km 高度内误差 <2%（原文） |
| 出处 | 章节一 §1.2.4，image136 |
| 独立实现 | `elevationOf(d,h)`（反解），案例里用 `atan(h/d) − d/(2R)` |
| 数值验证 | 深圳 −0.326°（原文 −0.32）、伊春 1.744°（1.75）✅ |
| 近似边界 | 视线接近地平线时高次项不可忽略（原文自己也提醒过） |

### F3 霞光最大深入距离（原文图 image94）

| 项 | 内容 |
|---|---|
| 表达式 | `|l_f|max = 2·√(2R·h_CB)` |
| 变量/单位 | l[km]、h_CB[km] |
| 适用条件 | 平底单层云、云下无遮挡、把光线当地表切线抛物线 |
| 出处 | 章节一 §1.2.2，image94 |
| 独立实现 | `glowDepth(h) = 2*sqrt(2*R*h)` |

| 近似边界 | **精确式仍是待核实（W1）**：原文"精确列"比 `2√(2Rh)` 小 0.01–0.34 km，说明精确解含更高阶曲率项，但精确式图片未找到 |

### F4 远边界光线（原文图 image76）

| 项 | 内容 |
|---|---|
| 表达式 | `h_f(l,t) = (l − v·t)² / (2R)` |
| 变量/单位 | l[km]、t[min]、v[km/min] → h[km] |
| 适用条件 | 该光线与地表相切（地球阴影边界） |
| 出处 | 章节一 §1.2.2 图 1.14，image76 |

| 近似边界 | 平坦地球+抛物线近似；不含大气折射 |

### F5 近边界光线（原文图 image78）

| 项 | 内容 |
|---|---|
| 表达式 | `h_n(l,t) = (l−vt)²/(2R) + h_CB − (vt)²/(2R)` |
| 变量/单位 | 同上，h_CB[km] |
| 适用条件 | 该光线经过云边界点（l=0, h=h_CB）<br>验证：代入 l=0 得 h_n = h_CB ✅ |

| 近似边界 | 要求云层单层、边界竖直（无云幡）；云厚度忽略 |

### F6 火烧云三角边界（原文图 image86 / image88 / image90）

## 4. 三个案例复现（计算过程）

### 案例 1：深圳 2022-10-13 层积云晚霞

输入（原文给出）：h_CB=2000 m、云边界距离 d=200 km、v=21 km/min、日落 17:47、太阳方位 262°。

```
几何判据  2√(2R·h_CB) = 319.3 km > 200 km          → 几何上成立 ✅
边界高度角  atan(2/200) − 200/(2×6371) = 0.573° − 0.899° = −0.326°   （原文 −0.32°）✅
头顶窗口   t_start = d/(2v) = 200/42 = 4.76 min        （原文 4.8）✅
          t_end   = √(2Rh)/v = 159.6/21 = 7.60 min     （原文 7.6）✅
          持续 = 7.60 − 4.76 = 2.84 min                （原文 2.8）✅
5° 延伸    d₅ = 2/tan5° = 22.86 km → 22.86/21 = 1.09 min
          合计 = 2.84 + 1.09 = 3.93 min                （原文 3.9）✅
```
5/5 通过。**这也验证了 §2 F6 里"观察者位置换算"的推导是对的**（原文没写这一步）。

### 案例 2：伊春 2022-10-14 卷层云晚霞

输入：h_CB=7219 m、d=166 km、v=18 km/min；原文再用表 4.2 把云底修正到等效 4.65–5.90 km。

```
边界高度角  atan(7.219/166) − 166/(2×6371) = 2.491° − 0.746° = 1.744°   （原文 1.75）✅
开始       t_start = 166/(2×18) = 4.61 min（原写 4 分 36 秒 = 4.6）✅
等效云底 4.65 km：持续 = (√(2R·4.65) − 83)/18 = (243.4−83)/18 = 8.91 min  （原文 8'54"）✅
等效云底 5.90 km：持续 = (274.2−83)/18 = 10.62 min                        （原文 10'36"）✅
5° 延伸     82.55/18 = 4.59 min
合计       13.50–15.21 min                                                （原文 13'30"–15'12"）✅
```
6/6 通过。

### 案例 3：上海 2022-10-20 中云洞漏光

输入：云洞近边界 380 km、等效云底 3.5–5.0 km、真实云底 6.5 km、v=20 km/min。

```
几何判据  2√(2R·3.5) = 422 km、2√(2R·5.0) = 505 km，均 > 380 km ✅
开始      380/(2×20) = 9.5 min（原文 9.5）✅
持续      下限 (211.2−190)/20 = 1.06 min（原文 1.1）✅
          上限 (252.4−190)/20 = 3.12 min（原文 3.1）✅
5° 延伸   74.3/20 = 3.71 min（原文 3.7）✅
合计      1.06+3.71 = 4.77 min；3.12+3.71 = 6.83 min
          ⚠ 原文写「3.8~6.8 min」→ 算术不一致：1.1+3.7=4.8，不应是 3.8
```

**报告差异（不强行匹配）**：上限 6.83 vs 原文 6.8 属舍入，可接受；
下限 4.77 vs 原文 3.8 是原文自身加减错误（正文那句"两者相加得到 3.8"与前面的 1.1、3.7 矛盾）。
我们保留复算值 4.8，并在文档里注明原文笔误，**不调参去凑 3.8**。

## 7. GFS 云体阈值专项审查（重要修正）

### 7.1 审查方法

用同一轮起报（20261031 12Z，f020–f023）的 4 个时次 × 9 层 × 23×17 格点（名义 3 519 点/时次），
以及另一轮起报（20261031 00Z，f022/f023）做外推；另做棋盘格空间切半。
评价指标除原文的 POD/FAR，**额外计算精确率 PPV = hit/(hit+falseAlarm)**——因为"有云点"只占 1.3–2.2%，
FAR 相对巨大晴空分母会严重低估误报的严重程度。

### 7.2 逐时效稳定性（阈值 2×10⁻⁶ kg/kg）

| 时效 | 有云点占比 | POD | FAR | **PPV** |
|---|---|---|---|---|
| f020 | 2.22% | 0.987 | 0.0116 | **0.658** |
| f021 | 1.96% | 0.986 | 0.0087 | **0.694** |
| f022 | 1.73% | 0.967 | 0.0095 | **0.641** |
| f023 | 1.28% | 0.933 | 0.0086 | **0.583** |

→ 时效越远，POD 与 PPV 都下降（云越少越难判），阈值本身**基本稳定**。

### 7.3 时空独立性

| 切分方式 | 结果 |
|---|---|
| 时间外推（f020 标定 → f021/22/23 测试） | POD 0.986/0.967/0.933，**PPV 0.694/0.641/0.583** |
| 空间棋盘格切半 | POD 0.974–1.0，PPV 0.655–0.661 |
| **跨起报外推**（12Z 定阈值 → 00Z 检验） | POD 0.911/0.979，FAR 0.0181/0.0184，**PPV 0.394/0.418** |

**有效样本量**：名义 3 519 点/时次，但 TCDC 一阶自相关 i=0.317、j=0.350，
折算后**有效独立样本 ≈ 879/时次，4 个时次合计约 439**（不是 14 076）。
所以"14 076 个样本"只是格点总数，**不能当独立样本数**。

### 7.4 分相适用性（最关键的问题）

| 温度相 | 样本数 | 模式有云点 | @2e-6 POD | @2e-6 FAR |
|---|---|---|---|---|
| 冰云（<−20°C） | 782 | 78 | 0.987 | 0.034 |
| 混合相（−20~−5°C） | 391 | **0** | — | 0 |
| 暖云（>−5°C） | 2 346 | **0** | — | 0.007 |

**该时次海南窗内所有"有云点"全部在 −20°C 以下**。因此：
- 这次标定本质上是**冰云标定**；
- 暖云与混合相的阈值**本轮没有任何样本支持**（暖云 0 个有云点）；
- 液态云与冰晶云**必须分开判据**：逐层相关分析显示，850 hPa 上 corr(TCDC, CLWMR)=0.94，
  300 hPa 上 corr(TCDC, ICMR)=0.75、200 hPa 上 0.955——不同层/相态的对应关系完全不同，
  用一个全局阈值把液水与冰水混在一起是不严谨的。

### 7.5 TCDC 与 CLWMR/ICMR 的物理关系

- `TCDC` 是**层云量（%）**，描述"这一层有多少比例被云占据"；
  `CLWMR/ICMR` 是**水物质质量混合比（kg/kg）**，描述"云有多浓"。两者不是同一物理量。
- 实测：TCDC≥50% 处 qt 的中位数在 300 hPa 为 2.1×10⁻⁵、200 hPa 为 6.7×10⁻⁶ kg/kg；
  晴空处（TCDC≤10%）qt 的 99 分位只有 5.9×10⁻⁶（300 hPa）。→ **云量高不一定凝结水多**，
  这正是"用云量标定质量阈值只是经验映射"的直接证据。
- 因此上一份报告里的措辞必须修正：**这是经验性阈值标定，不是真实云水物理阈值，更不是普适定律**。

### 7.6 修正后的表述（已写回 `docs/阶段五-02`）

> 用 GFS 自身云分数 TCDC≥50% 作参照，对总凝结水 qt 做了**经验性阈值标定**：
> 阈值为 2×10⁻⁶ kg/kg 时，同轮 POD≈0.93–0.99、FAR≈0.9–1.2%、**精确率 PPV≈0.58–0.69**；
> 跨另一轮起报时 PPV≈0.39–0.42。样本以冰云为主（暖云/混合相无样本），
> 有效独立样本约数百。**该阈值仅用于"画图时区分有没有云"的显示目的，
> 不得解释为真实云水物理阈值，也不得用于统计推断。**
